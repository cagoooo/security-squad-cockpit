1. 先閱讀本 README、`AGENTS.md`（若有）、套件腳本與部署設定。

4. 修改後至少驗證開始、遊玩、計分／勝負、重新開始，以及手機與桌面版面。
5. 不要捏造尚未存在的功能；README 與實作有落差時，應同時更新文件。
